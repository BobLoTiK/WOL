# 🖥️ Часть 1 — Настройка ПК (Windows)

> **Где:** за самим ПК (понадобится перезагрузка и вход в BIOS).
> **Сколько времени:** ~20 минут.
> **Что должно получиться:** ПК принимает SSH-подключение по домашней сети, а сетевой адаптер умеет будить компьютер после полного выключения.

На этом шаге вы ничего не устанавливаете на телефоны — только готовите ПК и **записываете его адреса**, которые позже впишете в `config/config.sh`.

## Что настраиваем и зачем

| Настройка | Зачем она нужна |
|---|---|
| `ErP` = Disabled в BIOS | иначе после выключения сетевая карта полностью обесточена и пакет «проснись» ей не доходит |
| `Wake on LAN` в BIOS + `Wake on Magic Packet` в драйвере | разрешает пробуждение по сети |
| Отключённый «Быстрый запуск» Windows | при нём ПК после «выключения» уходит в гибридный сон, и WOL не работает |
| OpenSSH Server | по нему приходят команды `shutdown` / `reboot` / `sleep` и проверка связи |

---

## 1.1 · BIOS/UEFI

Перезагрузите ПК и нажмите клавишу входа в BIOS (обычно `Del`, `F2` или `F10` — смотрите надпись при загрузке).

Найдите и выставьте:

| Параметр | Значение | Где обычно лежит |
|---|---|---|
| `ErP` / `ErP Ready` / `EuP` | **Disabled** | Power / APM |
| `Wake on LAN` / `Power On By PCI-E` / `Resume by LAN` | **Enabled** | Power / Advanced / Onboard devices |

Сохраните и выйдите: **F10** → Yes.

> ⚠️ Если пункта Wake on LAN нет вообще — проверьте раздел `Power Management` или обновите прошивку платы. Иногда он называется `PME Event Wake Up`.

---

## 1.2 · Windows: выключаем «Быстрый запуск»

```
Панель управления ➡️ Электропитание ➡️ Действия кнопок питания
➡️ «Изменение параметров, которые сейчас недоступны»
➡️ снять галочку «Включить быстрый запуск (рекомендуется)» ➡️ Сохранить изменения
```

> 💡 Если галочка серая — нажмите «Изменение параметров, которые сейчас недоступны» (нужны права администратора).

---

## 1.3 · Windows: настраиваем сетевую карту

```
Диспетчер устройств ➡️ Сетевые адаптеры ➡️ (ваш Ethernet-адаптер, не Wi-Fi) ➡️ Свойства
```

**Вкладка «Управление электропитанием»** — включите всё:
- ☑ Разрешить этому устройству выводить компьютер из ждущего режима
- ☑ Разрешить только магическому пакету выводить компьютер из ждущего режима

**Вкладка «Дополнительно»** найдите и выставьте:

| Параметр | Значение |
|---|---|
| `Wake on Magic Packet` | **Enabled** |
| `Wake on pattern match` | Disabled (чтобы ПК не просыпался от любого сетевого шума) |
| `Энергосбережение` / `Green Ethernet` / `Ultra Low Power` | **Disabled** |

> ⚠️ Настраивать нужно **Ethernet**-адаптер. По Wi-Fi Wake-on-LAN на обычных ПК не работает.

## 1.4 · Открываем доступ по SSH

**Установка:**
```
Параметры ➡️ Система ➡️ Дополнительные компоненты ➡️ Просмотреть компоненты Windows
➡️ отметить «Служба OpenSSH Server» ➡️ Установить
```

**Запуск и автозапуск** (PowerShell **от имени администратора**):
```powershell
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'
```

**Разрешаем порт в брандмауэре:**
```powershell
New-NetFirewallRule -Name sshd -DisplayName 'OpenSSH Server (sshd)' `
  -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
```

> ⚠️ SSH пускает только учётки **с паролем**. Если у вас вход в Windows без пароля — задайте его: `net user <PC_USER> *`.

---

## 1.5 · Узнаём IP и MAC адрес

Выполните в `cmd`:
```cmd
ipconfig /all
```
Найдите блок своего Ethernet-адаптера и выпишите два значения:

- **IPv4-адрес** — например `192.168.1.55` → это `PC_IP`
- **Физический адрес** — например `10-FF-E0-90-FC-7D` → это `PC_MAC`

> 💡 **Сильно советую закрепить IP.** Если роутер выдаст ПК другой адрес, скрипты перестанут работать.
> Закрепите адрес в настройках роутера (DHCP reservation) или задайте статический IP в Windows.

---

## 1.6 · Вписываем данные в конфиг

Значения понадобятся на шаге 3, когда будете заполнять `config/config.sh`:

| Переменная | Откуда взять | Пример |
|---|---|---|
| `PC_USER` | имя пользователя Windows (`whoami` в `cmd`) | `максим` |
| `PC_IP` | `IPv4-адрес` из `ipconfig /all` | `192.168.1.55` |
| `PC_MAC` | `Физический адрес` из `ipconfig /all` | `10-FF-E0-90-FC-7D` |
| `PC_BROADCAST` | первые три числа `PC_IP` + `.255` | `192.168.1.255` |

## ✅ Проверка

Выполняйте по порядку, на самом ПК:

**1. Служба запущена** (PowerShell):
```powershell
Get-Service sshd
```
Ожидается: `Status: Running`, `StartType: Automatic`.

**2. SSH отвечает локально** (`cmd` или PowerShell):
```cmd
ssh <PC_USER>@localhost hostname
```
Первый раз спросит `Are you sure you want to continue connecting?` → `yes`, затем пароль Windows.
Ожидается: имя компьютера.

**3. SSH отвечает из домашней сети** — с домашнего телефона (после части 2) или с любого другого устройства в том же Wi-Fi:
```bash
ssh <PC_USER>@<PC_IP> hostname
```
Ожидается: имя компьютера. Это подтверждает, что порт открыт и брандмауэр не мешает.

> 💡 Если на этом шаге всё работает — ПК готов. Реальную проверку просыпания (WOL) сделаете в части 5, когда будет готово реле.

---

## ❌ Если не получилось

| Симптом | Причина и решение |
|---|---|
| `Get-Service sshd` → `Stopped` | запустите `Start-Service sshd` от админа |
| `Connection refused` по `PC_IP` | служба не запущена, либо правило брандмауэра не создано |
| `Permission denied` при верном пароле | у учётки нет пароля, либо вводите не тот логин — проверьте `whoami` |
| `ssh: command not found` на ПК | клиент OpenSSH не установлен: добавьте компонент «Клиент OpenSSH» |
| ПК не просыпается (проверите позже) | вернитесь к 1.1–1.3: чаще всего виноваты `ErP`, «Быстрый запуск» или Wi-Fi вместо кабеля |
